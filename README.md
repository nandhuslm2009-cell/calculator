# Simple C++ Calculator

My first C++ program! 
This calculator does + - * / operations.

### How to run
1. Open in Dev C++
2. Press F11 to Compile & Run
3. Enter first number, operator, second number

Example:
ENTER FIRST NUMBER: 10
ENTER OPERATOR: +
ENTER SECOND NUMBER: 5
RESULT: 15
